# VKR Stats Analysis

## Проектирование АРМ менеджера салона красоты

Репозиторий содержит материалы выпускной квалификационной работы по теме
**«Проектирование автоматизированного рабочего места менеджера салона красоты»**.

Проект рассматривает работу менеджера студии перманентного макияжа и обучения
«Школа перманентного макияжа Ли Белекмы» в Улан-Удэ. Главная идея работы —
показать, как небольшой салон может перейти от разрозненного ручного учета к
понятному Excel-интерфейсу без покупки сложной CRM-системы.

## Проблема

В небольшом салоне менеджер одновременно отвечает за запись клиентов, расписание
мастеров, учет расходных материалов, заказы поставщикам, заявки на обучение и
оперативную отчетность для руководителя. Когда эти данные ведутся в мессенджерах,
бумажных журналах и отдельных файлах, работа становится зависимой от памяти,
ручных сверок и постоянных уточнений.

Такой подход приводит к типичным сбоям:

- двойные бронирования и пересечения в графике мастеров;
- потерянные заявки клиентов и учеников;
- несвоевременный заказ расходных материалов;
- ручной подсчет выручки, предоплат и загрузки;
- отсутствие единой картины дня для руководителя;
- рост операционных ошибок при увеличении числа записей.

Для малого бизнеса проблема особенно чувствительна: полноценная CRM может быть
дорогой, избыточной и сложной для быстрого внедрения, а ручной учет уже не дает
нужной надежности.

## Решение

В работе спроектировано автоматизированное рабочее место менеджера на базе
Microsoft Excel и совместимых табличных редакторов. Excel выбран как практичная
среда для малого салона: он знаком пользователям, не требует отдельной серверной
инфраструктуры, быстро настраивается и позволяет собрать рабочий прототип с
формулами, фильтрами, проверкой данных и сводными показателями.

Прототип АРМ включает главный экран и восемь рабочих листов:

| Лист | Назначение |
| --- | --- |
| Главный экран | Оперативная сводка по записям, материалам, заказам, обучению и финансам |
| Записи клиентов | Единый журнал процедур со статусами и оплатами |
| Мастера | Справочник сотрудников и их параметров работы |
| График | Планирование занятости мастеров и кабинетов |
| Расходники | Учет остатков и минимальных норм материалов |
| Заказы | Контроль заказов поставщикам и их статусов |
| Обучение | Учет заявок на курсы перманентного макияжа |
| Отчеты | Сводные показатели периода для руководителя |
| Справочники | Услуги, статусы, кабинеты, материалы и другие списки |

Внутри прототипа используются выпадающие списки, таблицы с фильтрами, формулы
контроля качества данных, условное форматирование и диаграмма операционной
сводки. Например, расходные материалы автоматически получают статус «заказать»,
если остаток становится ниже минимальной нормы.

## Методология

Проект построен не только как Excel-файл, но и как аналитическое обоснование
автоматизации. В работе использованы:

- системный анализ предметной области;
- моделирование процессов AS-IS и TO-BE;
- нотации IDEF0, BPMN, EPC и UML;
- функциональные и нефункциональные требования;
- оценка рисков IT-проекта;
- расчет затрат, эффекта и срока окупаемости.

Такой подход позволяет сначала понять текущий процесс, затем описать целевое
состояние и только после этого проектировать структуру данных и экранные формы.

## Экономический эффект

Расчеты показывают, что проект подходит для внедрения в малом салоне без крупных
капитальных затрат.

| Показатель | Значение |
| --- | ---: |
| Трудоемкость разработки | 80 часов |
| Расчетная ставка | 300 руб./час |
| Затраты на разработку | 24 000 руб. |
| Экономия времени менеджера | 1 620 минут в месяц |
| Экономия в часах | 27 часов в месяц |
| Денежный эффект | 8 100 руб. в месяц |
| Срок окупаемости | около 3 месяцев |

Экономия появляется за счет сокращения ручных сверок, ускорения поиска свободных
окон, более быстрого формирования отчетов и своевременного контроля расходников.

## Результаты внедрения

Ожидаемый результат проекта — не просто электронная таблица, а единое рабочее
пространство менеджера. Смена начинается с главного экрана: видны новые и
неподтвержденные записи, материалы ниже нормы, активные заказы, заявки на
обучение и ключевые финансовые показатели.

После внедрения меняется логика работы:

- менеджер ведет новые записи в одном журнале, а не в нескольких каналах;
- мастер получает более предсказуемое расписание;
- руководитель видит показатели без ручного запроса;
- клиент быстрее получает подтверждение записи;
- заявки на обучение не теряются среди процедурных записей.

Контрольные показатели качества данных помогают не допустить формального
использования файла. Для опытной эксплуатации заданы пороги по полноте статусов,
своевременности обновления записей, точности остатков и заполненности
справочников.

## Ограничения

Excel-прототип осознанно выбран как минимально достаточное решение. У него есть
ограничения:

- зависимость от дисциплины ручного ввода;
- риск конфликтов версий при одновременной работе;
- необходимость защищать персональные данные;
- ограниченная масштабируемость при росте числа мастеров, кабинетов и филиалов.

Эти риски компенсируются регламентом заполнения, резервным копированием, закрытыми
списками, защитой служебных областей и ограничением доступа к файлу. Если салон
вырастет, структура прототипа может стать техническим заданием для перехода на
облачную CRM или веб-систему.

## Выводы

Цель работы достигнута: спроектировано АРМ менеджера салона красоты на базе
Excel-интерфейса и описан рабочий прототип, который объединяет учет клиентов,
график мастеров, расходные материалы, заказы поставщикам, обучение и отчетность.

Главный вывод проекта: для небольшого салона автоматизация не обязана начинаться
с дорогой CRM. Если процессы описаны, требования сформулированы, а данные
собраны в единую структуру, даже Excel может стать полезным управленческим
инструментом. Такое решение снижает операционную нагрузку на менеджера, делает
работу салона прозрачнее для руководителя и создает основу для дальнейшей
цифровизации.
